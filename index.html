Elvis Drive Backup

A personal backup and synchronization setup using rclone to sync a designated folder on an external drive to Google Drive.

How it works

The account owner authorizes rclone through Google sign-in. Synchronization runs on the owner's computers and transfers files directly between those computers and Google Drive.

Mirror synchronization can create, update, and delete files in the configured Google Drive destination to match the source.

About this website

This website provides information only. It does not receive backup files, Google passwords, or authorization tokens.
